## Context

The meaning of copying and deleting during backup was previously unresolved.

## Alternatives

1. Maintain an independent backup without relocating files by category.
2. Mirror the source folder, including source deletions.

## Decision

Use classified archiving: copy selected files into destination folders according to their categories.

## Reason

The user described archiving Downloads into category-specific folders such as pictures, movies, and installers.

## Consequences

Destination organization may differ from the source folder structure. Source deletion requires separate confirmation.
