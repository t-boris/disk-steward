## Context

First-release automation also requires an explicit boundary on deletion authority.

## Alternatives

1. Automatically delete approved categories.
2. Automatically delete personal files according to rules.

## Decision

Require user confirmation before every cleanup operation that deletes data.

## Reason

The user explicitly selected cleanup only after confirmation.

## Consequences

Automated maintenance can identify and prepare cleanup, but must wait for confirmation before deleting data, including archived originals.
