## Context

First-release automated archiving requires a launch condition.

## Alternatives

1. Archive when the destination disk connects.
2. Archive when free space falls below a threshold.
3. Support a combination of triggers.

## Decision

Run automated archiving on a user-defined schedule.

## Reason

The user selected predictable scheduled archiving with deferred execution when the destination is unavailable.

## Consequences

Scheduled runs must wait for an unavailable destination disk and resume when it becomes available.
