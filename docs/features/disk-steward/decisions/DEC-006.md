## Context

Implementation plan I-9 and REQ-006 require resolving deletion mechanics for user-confirmed cleanup of user files, archived originals, caches, node_modules, and Docker artifacts.

## Alternatives

1. Always move files to macOS Trash only (Docker via Docker CLI)
2. Always permanently delete files immediately upon confirmation

## Decision

Move files and directories to macOS Trash by default upon user confirmation, with an explicit option in the confirmation dialog to permanently delete instead. Remove Docker artifacts via the Docker CLI after confirmation.

## Reason

Confirmed by the user in conversation to balance data safety (recoverable Trash by default) with immediate space reclamation when explicitly requested.

## Consequences

File and folder cleanup defaults to recoverable macOS Trash while allowing explicit permanent deletion in the confirmation dialog; Docker artifacts are removed via the Docker CLI after confirmation. Every deletion revalidates selected items immediately before execution.
