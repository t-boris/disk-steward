## Context

Implementation plan I-5 and REQ-005 required defining how classified archiving handles source files that do not match any user-defined file-type, file-name, or source-folder rule.

## Alternatives

1. Always leave unmatched files untouched without copying
2. Always require a default destination folder and route all unmatched files there

## Decision

Route unmatched files to an optional user-configured fallback destination folder when set; otherwise leave unmatched files untouched in their source location.

## Reason

Confirmed by the user in conversation to allow strict rule-only archiving by default while supporting catch-all archiving when desired.

## Consequences

Archive jobs can optionally configure a fallback destination folder for files that match no explicit classification rule; if unset, unmatched files remain untouched and are reported as skipped in the plan preview and run summary.
