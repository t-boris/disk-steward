## Context

The repository contained only specification documents with no existing application code, versioning policy, or deployment target configured.

## Alternatives

1. Native Swift/SwiftUI app starting at 0.1.0 installed to ~/Applications/Disk Steward.app
2. Native Swift/SwiftUI app starting at 1.0.0 built only in ./dist/Disk Steward.app without installing to /Applications

## Decision

Build Disk Steward as a native Swift/SwiftUI macOS application using Semantic Versioning starting at 1.0.0 (tracked in VERSION and Info.plist), signed with the local signing certificate, and deployed locally by installing the Release bundle to /Applications/Disk Steward.app.

## Reason

Confirmed by the user in conversation to provide a native, non-sandboxed personal macOS app with menu bar integration, full volume access, Docker CLI integration, and a clean local release/deploy workflow.

## Consequences

The project is structured as a Swift Package + native macOS .app bundle builder with VERSION file, Info.plist synchronization, local code signing, and a reproducible scripts/release.sh that builds, signs, installs to /Applications/Disk Steward.app, and verifies the deployed bundle version.
