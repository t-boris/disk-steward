## Context

After reviewing Disk Steward v1.0.1 on macOS, the user reported that coloring treemap tiles by age or file type produced uniform monotone blocks and obscured nested folder structure.

## Alternatives

1. Color treemap tiles by modification date age or file category with a mode switcher

## Decision

Render the treemap strictly one hierarchy level at a time (direct children of the currently selected disk or folder), sized strictly proportionally to allocated bytes and colored with vivid contrasting deterministic colors for adjacent rectangles without a color-mode switcher. Clicking any folder drills down into it and displays its single-level direct children in the same layout.

## Reason

Explicit user feedback directing that the treemap should focus purely on nested structural size representation with distinct adjacent colors and single-click category filtering inside any folder.

## Consequences

Treemap renders multi-level nested folders and files strictly proportional to allocated size using a high-contrast deterministic palette where adjacent siblings and nested levels always have distinct colors. The treemap color-mode toggle is removed; file-type and date filters narrow the active folder scope, and date breakdowns remain available in the By Date inspector tab.
