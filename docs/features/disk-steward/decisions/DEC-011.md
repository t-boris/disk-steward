## Context

The user requested richer cleanup workflows allowing them to pick a specific folder and remove matching files recursively according to rules (such as all code files, ZIP archives, or video files).

## Alternatives

1. Limit cleanup proposals solely to automatic global discovery of large files, caches, Docker, and node_modules

## Decision

Support rule-based recursive folder cleanup where the user specifies a target folder and matching criteria (file categories, custom extensions such as zip/mp4, filename pattern, optional age and size), previews matched files, optionally saves reusable rules, and executes deletion after confirmation.

## Reason

Explicit user feedback requesting targeted rule-driven cleanup inside user-selected folders.

## Consequences

Adds CleanupRule and CleanupRuleEngine allowing the user to select any target folder and match files recursively by file category (e.g. Code, Videos, Archives), specific extensions (e.g. .zip), filename pattern, age, and minimum size, with reusable saved rules and direct launch from any folder in Storage Explorer. Execution continues to require explicit user confirmation (DEC-003) and defaults to Move to Trash with optional Permanent Delete (DEC-006).
