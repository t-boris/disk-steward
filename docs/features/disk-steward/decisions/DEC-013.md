## Context

The user reported seeing dozens of recurring Cleanup Proposals for folders/items they already decided to keep and requested a way to dismiss/ignore items and folders persistently.

## Alternatives

1. Show all automatically discovered cleanup candidates repeatedly without an ignore/dismiss mechanism

## Decision

Allow the user to persistently dismiss individual Cleanup Proposals (single item or bulk selected items) or exclude an entire containing folder, persisting exclusions in configuration so ignored items never reappear in proposals or badge counts until explicitly restored.

## Reason

Explicit user request to silence unwanted cleanup proposals and remember ignored folders across sessions.

## Consequences

AppConfiguration persists CleanupExclusion entries (matching exact candidate IDs, exact paths, or excluded folder prefixes). CleanupScanner automatically filters out excluded candidates so dismissed items and ignored folders never reappear or inflate badge counts across refreshes or restarts, while an Ignored Items popover lets the user review and restore any exclusion at any time.
