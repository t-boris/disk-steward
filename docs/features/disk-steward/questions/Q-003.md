## Question

Какие полномочия по удалению данных вы хотите дать приложению?

## Why it matters

Постоянное наблюдение за диском уже заявлено, но степень самостоятельности при очистке пока не определена.

## Options

- **A**: Приложение предлагает очистку, а удаляет только после подтверждения.
- **B**: Автоматически чистит только разрешённые категории, например выбранные кэши и зависимости; личные файлы — с подтверждением.
- **C**: Может автоматически удалять и личные файлы по заданным вами правилам.

## Recommended

A — На первом этапе полезно проверить качество рекомендаций до предоставления права на автоматическое удаление.

## Answer

A. Приложение предлагает очистку, а удаляет только после подтверждения.
