## Summary

The source describes a personal macOS application with menu bar access and a full window for visually understanding storage usage across the main disk and additional storage disks. It combines interactive storage exploration with selected-folder backups and cleanup of files, caches, and development artifacts. Automatic behavior is part of the stated ambition, but first-release boundaries, automation rules, and deletion semantics remain unconfirmed.

intake
