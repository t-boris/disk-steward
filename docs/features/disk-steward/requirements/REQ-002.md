## Statement

Monitor storage capacity and usage across the user's main disk and additional storage disks.

## Acceptance Criteria

- [ ] The user can inspect total, used, and free space for the main disk and connected additional storage disks.
- [ ] Storage figures refresh during ongoing monitoring.
