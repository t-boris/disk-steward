## Statement

Provide a visual storage explorer that makes the largest consumers of disk space easy to identify.

## Acceptance Criteria

- [ ] The user can select a disk or folder for analysis.
- [ ] A treemap represents files and folders with areas proportional to their sizes.
- [ ] The user can identify the largest items within the selected scope.
