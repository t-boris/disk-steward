## Statement

Provide a visual storage explorer that makes the largest consumers of disk space easy to identify.

## Acceptance Criteria

- [x] The user can select a disk or folder for analysis.
- [x] A treemap represents files and folders with areas proportional to their sizes.
- [x] The user can identify the largest items within the selected scope.
