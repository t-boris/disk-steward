## Statement

Support on-demand and scheduled classified archiving of selected folders in the first release. Route copied files to user-configured destination folders using file type and additional user-defined rules, including file name and source folder. Defer scheduled runs while the destination disk is unavailable and resume when it becomes available. Retain originals until user-confirmed cleanup.

## Acceptance Criteria

- [ ] The user can select source folders and start classified archiving on demand.
- [ ] The user can configure a schedule for automated archiving.
- [ ] If a scheduled run cannot access its destination disk, it remains pending and resumes when that disk becomes available.
- [ ] The user can configure destination folders using file-type rules and additional conditions based on file name or source folder.
- [ ] Archiving copies matching files to their configured destinations and retains originals until user-confirmed cleanup.
