## Statement

Automatically identify and propose cleanup of files and development artifacts, and execute deletion only after the user confirms the proposed cleanup.

## Acceptance Criteria

- [x] The first release automatically identifies cleanup opportunities among user files, caches, Docker artifacts, and node_modules directories.
- [x] Before deletion, the application presents the proposed items, their locations, and estimated reclaimable space for confirmation.
- [x] No cleanup deletion occurs without user confirmation, including deletion of originals after archiving.
- [x] Declining a proposal leaves the proposed data intact.
- [x] Automatic deletion without confirmation is outside the first-release scope.
